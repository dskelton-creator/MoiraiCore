The difference is the gate.

Standalone agents are trusted to write wherever they like. MoiraiCore treats the model as a capable but untrusted contributor — and routes every change through a review gate the way a release engineer would.

WITHOUT A GATE
The agent writes to src/ directly. You review after the fact — if at all. A bot can commit broken, insecure, or unwanted code before anyone sees it.
WITH MOIRAICORE
Every task is decomposed → generated by a capable model → evaluated (syntax, security, structure) → merged only on approval. Direct writes to src/ are blocked.

A three-tier pipeline with a release engineer built in.

Not one all-powerful agent. A governed team where each tier does one job well and nothing reaches your codebase unexamined.

TIER 1 · SCRUMMASTER

Plans the work

Decomposes goals into a dependency-aware backlog. Routes each task to the right tier. Owns assignment and evaluation — the model never decides what to build next.

TIER 2 · ARCHITECT

Designs & generates

Produces blueprints and code with a provider-agnostic backend — your choice of DeepSeek, Gemini, OpenAI-compatible, or local models.

TIER 3 · BUILDER

Executes locally

Handles tight, single-file micro-fixes on your own machine via Ollama — fast, private, and free, with loop detection and iteration caps.

SCRUMGATE Everything flows here first: merge queue → evaluate (syntax + security) → merge to protected src/.

Runs where you do. Owns nothing you didn't share.
